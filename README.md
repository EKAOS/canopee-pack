# canopee-pack

Liste de mods lue par le launcher Canopée à chaque lancement.
Pour ajouter un mod : ajouter son identifiant Modrinth dans `mods` de `pack.json`.

## Mises à jour du launcher

Le dossier `launcher/` contient la dernière version du code du launcher. Au démarrage, chaque launcher lit `launcher/version.json` et télécharge les fichiers de `launcher/app/` si la version est plus récente.
